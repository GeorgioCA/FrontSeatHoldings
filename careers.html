→

  • Design, develop, and maintain full-stack web applications and internal tools
  • Architect scalable software solutions and make key technical decisions
  • Write clean, testable, and well-documented code following best practices
  • Mentor and provide technical guidance to junior and mid-level developers
  • Conduct code reviews and enforce coding standards
  • Collaborate with stakeholders to define project requirements and timelines
  • Optimize application performance, security, and reliability
  • Stay current with emerging technologies and propose adoption where beneficial

  • Strong proficiency in Python, JavaScript/TypeScript, or Go

  • Experience with cloud platforms: AWS, GCP, or Azure
  • Proficiency with Docker, CI/CD pipelines, and Git workflows
  • Experience leading development teams or mentoring junior developers
